# Roll Ball Practice

Unityで制作したボール操作ゲームです。

## 使用技術
- Unity
- C#

## ゲーム内容
- ボールを操作してステージ内のコインを回収するゲームです。

## 操作方法
- WASDで移動

## 学習内容
- GetAxisでのWASD移動
- LookAtでカメラが対象を見続ける
- 場外でリセット
- コイン3個以上回収でゲームクリアUI表示
